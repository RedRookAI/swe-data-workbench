# Frozen ingestion-quality demonstration

quality.json displays the exact scores in evaluation-before/evidence.json and evaluation-after/evidence.json. Both three-file evaluation exports verify with swe_workbench.evaluation_export.verify_evaluation. queue-export is the distinct legacy accepted-code format; its accepted JSONL is intentionally empty because this task-quality workflow makes no code-acceptance decisions.

recording.json identifies the actual silent browser replay and its original machine-evidence bindings. driver-receipt.json identifies the preceding installed-artifact account-free run. Later replay decisions have their own audit cuts and export identities; neither receipt rewrites earlier execution.

Original task, patches, exact candidate visibility and both calibration review inputs/outputs are under examples/ingest-recovery. Current scope and the open aggregate-overflow coverage limitation are in docs/task-quality.md.
