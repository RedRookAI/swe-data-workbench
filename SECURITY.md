# Security boundary

This application is a portfolio demonstration for trusted, manifest-listed synthetic/public coding fixtures. It does not accept arbitrary uploaded code for execution and does not establish a hostile-code sandbox.

The live application is owner-operated and authenticated. Its bearer token belongs in a request header, never a URL, exported evidence or a recording. Cross-origin mutation requests are refused. The public demonstration is static, with no upload, execution or mutation endpoints.

A local hash-linked audit trail helps identify changes relative to retained references; it is not independent custody or protection against an administrator replacing both data and every reference. Check success does not prove general correctness. A review decision binds exact versions and cannot bypass missing required evidence.

Use an isolated task directory. Do not point the application at another project's database/workspace or attach credentials to fixture processes. Do not expose the live execution API publicly. Review runtime requirements and the recorded verification profile before adapting it to another workload.


The optional change-handoff path is read-only toward its source project. Evidence attachments and field references are data; capture executes no supplied checks or commands. Unsigned external reports remain external even when they declare the selected source revision. Handoff readiness authorizes no source-project effects and cannot bypass native accepted-code gates. The public page renders selected snapshots as inert text.

Reusable profiles are explicitly selected data. Directory binding reads only declared names, refuses symlink slots and does not execute profile contents or scan a source project for configuration. Revision-role relationships are evidence-referenced declarations, not execution authentication. Unknown or mismatched candidate applicability blocks required readiness; comparison never reuses an approval automatically. Old v1 formats remain distinct from v2 metadata, and private inputs must stay out of public builds.
